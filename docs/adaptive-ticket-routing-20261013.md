# 過去1年：点数別レース分類の遡及検証（2026-10-13）

## 検証範囲と元データ
- 期間 2025-10-09～2026-10-08、予測 13,742 レース中 13,612 レースの確定着順で採点（不明・曖昧 130 件）。
- [条件付き3連単モデルの凍結予測](https://github.com/rokuda6898-jpg/keirin-ai-auto/actions/runs/38354967172)、[確定着順との照合](https://github.com/rokuda6898-jpg/keirin-ai-auto/actions/runs/37875807209)、[競輪場・級班・決まり手およびG1/G2/G3の開催区分](https://github.com/rokuda6898-jpg/keirin-ai-auto/actions/runs/38326215428)を使用。
- 元モデルの固定 k 点的中率: 3点=22.245%、8点=37.783%、12点=45.857%。18点=54.408%は**全レースを18点**で計算した参考値で、重賞限定ではない。
- 発走前に取得されたことが確認できない歴史的な特徴が含まれるため、実運用実績・完全未使用の独立ホールドアウトではない。オッズ・回収率・50/100倍超の的中改善は未検証。

## ポリシー
- 3・8・12点に加え、G1/G2/G3と明示確認できたレースのみ18点を許可（**上限であり強制ではない**）。
- 1日の全対象レースの購入点数合計を1レース当たり8/9/10点相当以下に制限し、上位k点予測的中確率の合計最大化を、正解ラベルを使わない動的計画法で解く。
- 予算配分時には着順欠損の130レースも含め、採点時のみ除外。
- 分類器の学習: 2025-10-09～2026-04-08の6,698レースのみ。評価: 2026-04-09～2026-10-08の6,914レース。
- さらに最初の60日を初期学習に使用し、その後の月次ウォークフォワード11,395レースを採点。

## 実測（同予算の比較）
| 検証法 | R数 | 8点固定 | 動的配分（平均約8点） | 差 |
|---|---:|---:|---:|---:|
| 全1年・予測確率だけで配分（追加学習なし） | 13,612 | 5,143的中 / 37.783% | **5,223的中 / 38.371%** | **+80件 / +0.588pt** |
| 後半6か月・前半だけで分類器学習 | 6,914 | 2,581 / 37.330% | **2,631 / 38.053%** | **+50件 / +0.723pt** |
| 60日初期学習＋月次更新 | 11,395 | 4,287 / 37.622% | **4,355 / 38.219%** | **+68件 / +0.597pt** |

- 全1年の差の**名目**日別95%区間は +0.273～+0.897pt、後半6か月は +0.234～+1.217pt。いずれもモデル試行の多重比較や既検証年への適応を補正しておらず、利益や再現性の証明ではない。
- 後半6か月の平均8点配分は **3点1,493R / 8点3,569R / 12点1,846R / 18点6R**。固定8点との差では救済186件・取りこぼし136件。
- 後半の平均9点では 2,765的中(39.991%)、平均10点では2,896的中(41.886%)。ただし単純に購入点数を増やしているため、同等費用の8点・12点確率増分配分と比較するとそれぞれ+19件・+8件で、名目区間はゼロをまたいだ。
- グレード区分の確定データがないレースは18点扱いにしない。検証した13,742予測中、開催区分を確認できたのは12,372件、G1/G2/G3と確認できたのは1,251件。

## 判定
平均8点のレース別配分は小幅に改善したが、本番サイト・note・有料販売への採用条件を満たさない。ベースとなる条件付き3連単モデルの品質と発走前データの時点証明を優先し、完全な締切前オッズ付きの新規レースで再検証する。**この記録は研究専用。現行予想・購入ロジックを変更しない。**

同じ1年の再現用コード・全集計JSON・7千レースの分類CSVは、同会話で生成した `keirin-adaptive-ticket-research.zip` に保管。
