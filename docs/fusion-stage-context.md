# 統合式の追加研究：着順の分業と条件別配分

従来の統合式・７部署・リスク部の現行評価と買い目を残し、研究用に３案を追加する。社長への自動採用・本番予想への組み込みは行わない。

## 比較する３案

1. **条件別配分**：出走人数×クラスごとに、全３連単分布を混ぜる配分を学習する。
2. **着順別配分**：各式の全３連単分布から、１着、２着｜１着、３着｜１・２着の条件付き分布を取り出す。３段階それぞれに別の配分を学習する。
3. **両方**：条件別配分を３段階ごとに学習する。

```
P_stage(a,b,c|x)
  = [Σ_g w_1g(x) p_g(a|x)]
  × [Σ_g w_2g(x) p_g(b|a,x)]
  × [Σ_g w_3g(x) p_g(c|a,b,x)]
```

各段階の重みは非負・合計１。同一予想の複製は従来の重複グループにまとめる。予想はすべての１・２着候補を列挙してから３着を評価する。正解の１・２着を予想時に渡さない。全３連単の合計は１。着順の分業は過信補正前の性質であり、後段の温度補正・旧統合式との混合後は段階別の配分そのものと最終寄与が一致するとは限らない。

１着に強い式と、条件付き３着に強い式を使い分ける余地を作る。部署名による固定の優遇、３着の一律加重、買い目の増加はしない。

## 古いデータ内での学習・選択

元の固定１年研究のモデル・入力・日付境界をそのまま再利用する。元の学習処理の各ファイルとデータ全体のハッシュを照合する。

- 2024-10-13〜2025-04-10：配分を学習。全体の元の配分を再現できることも照合する。
- 2025-04-11〜2025-10-08：各追加案の配合率（０、25、50、75、100％）と温度を対数損失で選択する。０％なら旧統合式のまま。
- 2025-10-09〜2026-10-08：固定済みの追加案で予想を先に保存し、別工程で評価する。

条件別の学習は100レース・14日以上で行う。重みの学習は全体の配分を事前値とし、さらに `n/(n+300)` の割合だけ条件別配分へ動かす。件数不足や未知の条件は全体の配分へ戻る。この最低件数は実装上の制限であり、十分な精度の証明ではない。基礎分類器・部署プロフィールは前回の2023-10-17時点の固定物を再利用する。全旧データでの再学習ではない。

## 検証の扱い

今回のアイデアは前回の１年の結果を見た後に考案している。そのため係数の学習にその１年を使わなくても、**新しい未使用期間の検証とは呼ばない**。候補３案をすべて報告し、同じ年を見て係数を追加調整しない。月・人数・クラス、１／６／12候補、確率の損失、従来統合式から救えた的中・失った的中を残す。

過去の締切前オッズがないため、今回は無価格の予想候補だけを比較する。本線・100倍以上の穴・同金額での回収率・高配当依存については未検証。過去の事前予想台帳には加算しない。改善しても直ちに社長の本番判断への採用合格とはしない。

## 出典と実装の違い

条件に応じてモデル配分を変える考え方の参考：Yao et al., [Bayesian hierarchical stacking: Some models are (somewhere) useful](https://arxiv.org/abs/2101.08954)。本実装は縮約付きの離散条件配分と条件付き確率の連鎖を組み合わせたもので、論文のベイズモデルの再現ではない。競輪での改善を保証する根拠にも用いない。

実行は `fusion-stage-research` の手動または研究専用ブランチ更新時のみ。定期学習・本番採用・購入処理は含まない。元のアーカイブとモデルがなければ停止し、代替の架空データで本成績を出さない。
