# 部署別判断を買い目に接続する変更

既存の専門コンテキストは比較実験でのみ使われ、公開部署予想では使われていなかった。
v3は同じ専門コンテキストを部署の着順候補と買い目の両方に接続する。

- データ部：同格・同人数・相手強度が近い過去成績で2、3着を補正。
- 展開部：確認済みの複数ラインの先行候補と行動観測を使い、選んだ1、2着に応じて残る候補を評価。
- ライン部：確認済みのラインと番手別実績を使い、同ラインの追走順序を評価。未確認の番手実績補正は停止。
- リスク部：評価式と買い目選別を従来のまま維持。
- 軍師：各部署の評価をまとめる。まとめ直した結論をもう1票として再加算しない。

各部署の順位スコアをs、専門評価をCとすると、買い目の重みは
P(a) × normalize[s2(b) C(a,b)] × normalize[s3(c) C(a,b,c)]。
1、2着で使用済みの選手は除く。専門評価は観測量で縮小し、根拠のない違いは作らない。
これは校正済みの実現確率ではなく、検証対象の評価式。

専門データ不足では既存の基本評価を使い、その理由を記録する。
全選手の専門履歴が欠け同じモデルに戻った部署は、同じ順位の提案を1票として分ける。
独立した根拠で同じ結論に至った部署は、その一致を減点しない。
部署ごとに必ず違う買い目を出す保証はしない。

各部署の本線・穴の点数は従来選別の点数以下、穴100倍以上を維持。
既に固定した会社予想・締切済み予想は書き換えず、今後初めて保存される予想から適用。
新旧の予想方式を区別できるようバージョン・専門根拠・投票重みを台帳に記録。

## 確認

リスク部不変、締切後保存禁止、同根拠の二重加算防止、独立一致の維持、点数・穴オッズ制限をテスト。
既存の署名付き事前比較記録は79件有効、不正0件。条件付き市場評価あり／専門評価追加の
同レース・同時点・同点数・同額比較では、データ部の穴19件中18件、展開部7件中4件、
ライン部19件中13件で買い目が変化した。詳細はspecialist-context-validation.json。
これは専門条件が買い目に効くことの診断であり、今回のv3の的中率改善を証明しない。
比較不能な記録を補充せず、精度・回収率の結論は今後の締切前比較で出す。
