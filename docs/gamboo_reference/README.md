# Gamboo 決まり手データ：保存用資料

## 原典
- Gamboo 遠山競輪研究所 競輪場データ集: https://gamboo.jp/pages/?tid=tohyama_bank_LP
- 集計期間（画像に記載）: 2020年10月〜2025年9月
- 提供資料: ユーザーが2026-10-13にチャットへ添付した `IMG_0967.png`、`IMG_0971.png`
- 数値の取り込み: **添付画像から読み取れる箇所だけを転記**。
- 原典サイトは外部から JavaScript 認証に阻まれ、全ページHTMLの自動取得は未達（直接 HTTP 202/空応答）。
- 43場の全数値、A級/S級ごとの分類、時間帯分類は **このCSVには未収録**。
- `class_scope=not_separated_on_screenshot` は、級班別を推定・混合していないことを示す。
- `row_type=bank_average` は「500平 均」であり独立の競輪場ではない。
- `first_second_method_pair` の組み合わせは「1着・2着」の順序。例: 逃マ=1着逃/2着マーク。
- 表示比率は小数第1位で丸められており、合計100.0％にならないことがある。
- 画像にある400mバンクの2着について、見えている函館・青森の行のみ収録。他行は未収録。
- この資料は参考統計であり、実際のレース履歴に対する発走前の予測特徴や回収率の検証結果とは区別する。

## ファイル
- `gamboo_bank_decisive_methods_screenshots.csv`：添付画像からの構造化転記（60レコード）。
- 種別: `first_place_method`（1着決まり手）、`second_place_method`（2着決まり手）、`first_second_method_pair`（1・2着決まり手組み合わせ）。

## 今後の保存
ページの直接取得が可能になれば同じ列に、出典URL・対象期間・級班条件を明記した別データとして追加する。取得不能な他場・階級・時間帯を補完値で捏造しない。
