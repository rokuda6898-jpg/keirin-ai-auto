# 買い目と金額の表示修正（2026-10-11）

買い目の直下に「購入額（配分）○○円」を太字で表示。別表を探さなくても、どの車券に何円か分かるようにする。合計1万円とオッズの取得時刻を買い目一覧の直前に置く。成績欄は買い目一覧の後へ移動した。

表示は買い目文字列で対応付ける。並び順を金額の対応付けに使わない。全買い目の一致、重複なし、100円単位、合計1万円を確認できない配分は金額を表示しない。未配分を一律100円や0円で穴埋めせず、未算出・見送りの理由を同じ場所に出す。

## 初回配分の追加
前版では導入前の全予想を一律に配分対象外としていたため、朝に保存済みの当日予想に金額が付かなかった。この点に限り、旧文書の「導入前は一律後付け禁止」を以下の前向き初回配分に更新する。

- `conditional_budget_initial.py` が、当日・締切60秒超前・公式結果なし・配分記録なしの保存予想だけを対象にする。
- 買い目、確率、元の予想保存時刻は変更しない。
- 実際に取得した時刻を保存し、`odds_basis=initial_allocation_after_forecast` と明記。元の予想時のオッズを再現したとは扱わない。
- 既に配分／見送り／算出不可の判断が保存されているものは変更しない。結果済み・締切済みの過去レースには金額を付けない。
- 公式払戻による結果後精算、仮想購入表示、自動投票なしは従来どおり。
