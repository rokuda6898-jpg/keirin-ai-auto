## 39Rの合算は参考値

最初の32Rと追加7Rを単純合算すると、従来方式は24/39的中、投資59,400円・払戻54,950円・回収率92.508418%。10点案は21/39的中、投資39,000円・払戻39,370円・回収率100.948718%（+370円）。

## 再計算

リポジトリのルートで実行する。以下は保存した全確率から10点の選択、フォーメーションの展開、公式払戻による精算、7Rと39Rの集計を再計算する。元データを変更せず、出力先が既にある場合は停止する。

```bash
PYTHONPATH=src python3 research/nexus_forward_initial_check.py \
  --evidence outputs/nexus_forward_initial_check_2026-10-20.json \
  --prior-report outputs/nexus_recent_roi_2026-10-20.json \
  --output /tmp/nexus-fixed10-new7-recomputed.json
```

モデル推論から確率も再生成する場合は、上記の固定コミットから取り出した7入力と19モデル・マニフェスト・履歴を明示する。下記の `frozen/` は固定データを配置したディレクトリで、可変の最新データで代用しない。

```bash
PYTHONPATH=src python3 research/nexus_forward_initial_check.py \
  --evidence outputs/nexus_forward_initial_check_2026-10-20.json \
  --prior-report outputs/nexus_recent_roi_2026-10-20.json \
  --inputs-dir frozen/preclose \
  --model-dir frozen/models/nexus53 \
  --history frozen/history.json.gz \
  --output /tmp/nexus-fixed10-new7-model-recomputed.json
```

入力は `<レースID>.json` または `input_<レースID>.json`。チェックサムと元予測の一致を要求し、別のデータに置き換えて計算を続行することはない。再計算コードはネットワークアクセス、予想の公開、実際の投票を行わない。
